# 🤖 AI Chatbot - دردشة ذكية مجانية

chatbot ذكي يعمل مباشرة في المتصفح بدون الحاجة إلى خادم أو اشتراكات مدفوعة!

## ✨ المميزات

- ✅ **مجاني 100%** - بدون تكاليف أو رسوم إضافية
- ✅ **يعمل بدون إنترنت** - كل المعالجة تحدث محلياً
- ✅ **دعم اللغة العربية** - محادثة طبيعية بالعربية
- ✅ **واجهة جميلة** - تصميم عصري وسهل الاستخدام
- ✅ **ردود ذكية** - معالجة طبيعية للنصوص
- ✅ **حفظ المحادثات** - تخزين المحادثات في المتصفح
- ✅ **سريع وخفيف** - لا يحتاج موارد كبيرة

## 🚀 كيفية الاستخدام

### الطريقة 1: مباشر من GitHub Pages
1. انتظر تفعيل GitHub Pages على الـ Repository
2. ادخل على الرابط: `https://OtmanMomo.github.io/AI-Chatbot`

### الطريقة 2: تشغيل محلي
```bash
# انسخ الـ Repository
git clone https://github.com/OtmanMomo/AI-Chatbot.git

# ادخل المجلد
cd AI-Chatbot

# استخدم أي خادم ويب (مثلا Python)
python -m http.server 8000

# ثم ادخل على: http://localhost:8000
```

### الطريقة 3: فتح الملف مباشرة
1. حمل الملفات
2. افتح `index.html` مباشرة في المتصفح

## 📝 كيفية تطوير الـ Chatbot

### إضافة إجابات جديدة

في الملف `ai.js`، ابحث عن الدالة `initializeResponses()` وأضف:

```javascript
'سؤالك هنا': 'الإجابة هنا',
'سؤال آخر': 'إجابة أخرى',
```

مثال:
```javascript
'ما هو React': 'React مكتبة JavaScript لبناء الواجهات! ⚛️',
'أين تعيش': 'أنا أعيش في السحابة! ☁️',
```

### تخصيص الألوان

في `index.html` في قسم `<style>`، غير:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
